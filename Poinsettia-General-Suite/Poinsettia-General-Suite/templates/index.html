Version History

v4.0.0
Poinsettia 4.0 “Fax” and “Candor” — Available now
  • Fax is the friendlier, more creative P4 model; Candor is direct and straight to the point
  • Two new web-connected P4 models with real-time search, citations, and weather support
  • Image upload is supported; audio import and microphone controls are intentionally unavailable
  • Separate model histories are preserved for Fax and Candor
Version 3.9
Poinsettia 3.9 — September 2026
  • Retains Poinsettia 3.8 web search, citations, weather, and downloadable file creation
  • Uses a base model credited to Google DeepMind
  • Native image understanding through the multimodal chat bar
  • Imported and recorded speech/audio input
  • Persistent, user-scoped chat histories and full chat management
LTS 3.8
Poinsettia 3.8 “Billions” — August 2026
  • Poinsettia 3 was upgraded to Poinsettia 3.8 “Billions”
v3.2.0
July Update — July 2026
  • Conversation history saved across page refreshes
  • Source citations shown under every P3 response
  • AI topic classification with instant regex fallback (no more timeouts)
  • Context cap raised from 1,200 to 2,500 characters
  • Favicon added
v3.0.0
July 2026
  • Poinsettia 3 — real-time internet-connected mode
  • Live web search via Wikipedia & trusted sources
  • Offline detection with clear user messaging
  • Separate conversation histories per model
  • P2 and P3 toggle in chat header
v2.0.0
December 2025
  • Streamlined architecture - removed legacy code
  • Deprecated Poinsettia 1 (web search)
  • AI-powered responses only
  • Cleaner, faster codebase
v1.2.0
December 2025
  • New Outfit font for cleaner interface
  • Added Version History
  • Updated logo design
  • Mobile responsive improvements
v1.0.0
October 2025
  • Initial release
  • Dark theme interface
