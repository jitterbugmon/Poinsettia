Poinsettia General Suite

Poinsettia Documentation

Product, architecture, multimodal input, and licensing information for the Poinsettia General Suite and its Poinsettia 2, 3.9, and 4.0 AI models.

02Distinction of Poinsettia AI Models

The Poinsettia General Suite utilizes underlying artificial intelligence components designated as the Poinsettia 2, Poinsettia 3.9, and Poinsettia 4.0 models. These models are strictly separate and distinct architectural layers from the Poinsettia General Suite software framework.

Poinsettia 2

The general-purpose conversational model available through the Poinsettia chat experience. Poinsettia 2.9 uses gemma4:e4b base weights developed and released by Google DeepMind / Google under the Apache License, Version 2.0.

Poinsettia 3.9

The Gemma 4 12B-powered internet-connected model layer. It retains real-time search, weather, source citations, and downloadable file creation while adding native image and speech/audio understanding.

Poinsettia 4.0 “Fax”

The friendly, creative, image-capable P4 edition. Fax uses the gemma4:26b base model developed and released by Google DeepMind / Google.

Poinsettia 4.0 “Candor”

The direct, candid, image-capable P4 edition. Candor uses the gemma4:31b base model developed and released by Google DeepMind / Google.

03Base model attribution

Poinsettia 3.9 uses the gemma4:12b base model, developed and released by Google DeepMind / Google. Poinsettia 4.0 “Fax” uses gemma4:26b, and Poinsettia 4.0 “Candor” uses gemma4:31b; both P4 base models are developed and released by Google DeepMind / Google. Gemma 4 provides the multimodal architecture used for image input.

License: The applicable baseline model license is the Apache License, Version 2.0 for the unaltered gemma4:e4b, gemma4:12b, gemma4:26b, and gemma4:31b base models. Poinsettia application code, branding, prompts, UI, and proprietary configuration remain proprietary.

04Ollama Runtime Attribution

This project uses Ollama as a local runtime to run its configured language models. Ollama is a separate project; Poinsettia is not affiliated with, sponsored by, or endorsed by Ollama. For Ollama software, documentation, and licensing information, visit the official website and GitHub repository.

05Model Customization and Proprietary Weight Status

The Poinsettia 2, Poinsettia 3.9, and Poinsettia 4.0 models are derivative works built upon permissive open-source baselines.

The Alterations

The baseline models have been fundamentally altered, customized, and configured via a proprietary Modelfile, system prompt structures, and specialized parameters.

Proprietary Classification

The resulting trained weights, specific configurations, and unique behavioral modifications that comprise the fully realized Poinsettia 2, Poinsettia 3.9, and Poinsettia 4.0 models are proprietary and closed-source.
