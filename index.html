Setup.exe — unsigned beta

If the official release offers Poinsettia-<version>-Windows-x64-Setup.exe, download that asset and its SHA256SUMS.txt. This installer is unsigned: Windows cannot verify its publisher through a code-signing signature. A matching checksum confirms that the file matches the release; it does not prove that it is safe.

Before opening it, check its SHA-256. In File Explorer, use “Copy as path” on the downloaded installer. Open PowerShell, type Get-FileHash -Algorithm SHA256 -LiteralPath followed by a space and the copied, quoted path, then press Enter. Compare the Hash value with the installer’s entry in SHA256SUMS.txt. If the checksum is missing or does not match, stop.

The packaged installer includes the app’s Python runtime, so you do not need to install Python separately for this option. If Windows permits it without bypassing a security warning, follow setup, then launch Poinsettia for first-run Ollama and model downloads. SmartScreen or Smart App Control may still block this unsigned installer; cancel if Windows blocks it or reports an unknown publisher.

Keep Windows protection enabled

Poinsettia is intended to run a local AI assistant, but this website cannot guarantee that every release or downloaded dependency is malware-free. ZIP startup downloads Python packages; both installation paths download Ollama and model files. Use official sources and keep Smart App Control enabled.

If Windows blocks either installation path, stop. An unsigned Setup.exe is not a way around the restrictions on a batch launcher. Do not turn off Smart App Control or choose “Run anyway” for an unknown publisher.

A downloaded .bat file or the code it starts may be blocked. The ZIP’s “Unblock” option only removes its internet-download marker; it does not establish trust or override Smart App Control.

ZIP / .bat alternative — advanced

For users who intentionally choose the release ZIP. This path requires Python and may be blocked by Windows; use it only if the download is verified and Windows permits it without bypassing a warning.

  1. 01

    Install Python for Windows

    Download the latest stable 64-bit Python installer (3.11 or newer) from Python.org. Use the standard installer, not the embeddable ZIP, and enable “Add python.exe to PATH” if offered.

  2. 02

    Download the Windows ZIP

    Open the official Poinsettia releases and choose a Windows ZIP asset if offered. Verify the release’s checksum when provided. Use that release package, not GitHub’s automatically generated “Source code” archive.

  3. 03

    Extract the ZIP from Downloads

    In File Explorer, select the downloaded ZIP in Downloads, choose “Extract all,” pick a destination, then click “Extract.” Only if you have verified it came from the official release, you can use the ZIP’s Properties → “Unblock” option before extracting if Windows marks it as downloaded from the internet.

  4. 04

    Start Poinsettia

    Open the extracted folder and double-click start_poinsettia.bat. Keep the window open while setup installs dependencies, checks Ollama, and downloads the models. This needs internet and may take a while; Poinsettia opens in your browser when ready. If Windows blocks it or shows an unverified-publisher warning, cancel rather than bypassing the warning.

What runs where

Your models run locally.

Both Windows installation paths use Python and Ollama locally. The packaged Setup.exe includes Python; the ZIP/batch path requires Python installed separately. First-run setup downloads dependencies and models, and web research needs internet. This optional desktop distribution is separate from browser-based WebGPU inference.
