Get started

From download to workspace.

Install once. Poinsettia sets up its local runtime and opens your workspace. The first model download can take a while and needs an internet connection.

  1. 01

    Download the installer

    Use “Install latest version” when a Windows installer is available in the official GitHub release.

  2. 02

    Open it on your computer

    Windows asks you to run and approve downloaded software. A website cannot execute the installer for you.

  3. 03

    Set up, then begin

    Accept the first-run terms, let the local models download, and Poinsettia opens its workspace.

What runs where

Your models run locally.

The current Windows installer uses Ollama on your computer. Web research and first-time model downloads still use the internet. Browser-based WebGPU inference is not part of this installer yet.
